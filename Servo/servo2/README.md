ou# Servo2

Ce dossier contient un exemple de pilotage de servos avec ESP8266 et une carte PCA9685.

## Installation des bibliothèques nécessaires

Avant de téléverser le code, installez la bibliothèque suivante via le gestionnaire de bibliothèques Arduino :

- **Adafruit PWM Servo Driver** (`Adafruit_PWMServoDriver`)

La bibliothèque `Wire` est généralement incluse automatiquement avec le support ESP8266.

Sélectionnez la carte "Feather ESP8266" ou "Generic ESP8266" dans l'IDE Arduino.
